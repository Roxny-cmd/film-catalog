# film-catalog
Проект по проектному практикуму за 2 семестр 1 курса
Каталог с карточками фильмов и сериалов, под ними их названия дата выхода и страна выпустившая его, всего в строке 5 фильмов, отсортированных по фильтрам, при наведении карточка немного плавно уваличивается для удобства выбора. Слева расположенна лента с фильтрами (жанр, год, страна), переключение между фильмами и сериалами и поиск по названию. Справа ползунок, для переомтки страницы. Сам каталог выполнен в цветах градиетна черного и фиолетового. При нажатии на карточкк пользователя перебрасывает на страницу интересующего его фильма или сериала, на ней расположен постер, рейтинги, краткое описание, кадры, трейлер и ссылки на просмотр в оффициальных сервисах, нижевсего этого будут расположенны коментарии и поле для публикации своего и постановке оценки
