# film-catalog
Проект по проектному практикуму за 2 семестр 1 курса
Сревис-каталог фильмов и сериалов FilmCat
Представляет из себя простой каталог, в который зарегистрированный пользователь сам может добвалять интерисующие его картички фильмо и сериалов. Также он может добвалять в общий список платформы актёров, режисеров, страны, студии, жанры и платформы, на которых можно посмотреть материал
В каталоге реализован поиск по категориям и названиям
Проект учебный, поэтому в нём ограниченный функционал
