# film-catalog
Проект по проектному практикуму за 2 семестр 1 курса.
Сревис-каталог фильмов и сериалов FilmCat.
Представляет из себя простой каталог, в который зарегистрированный пользователь сам может добвалять интересующие его карточки фильмов и сериалов. Также он может добавлять в общий список платформы актёров, режиссеров, страны, студии, жанры и платформы, на которых можно посмотреть материал.
В каталоге реализован поиск по категориям и названиям.
Проект учебный, поэтому в нём ограниченный функционал
